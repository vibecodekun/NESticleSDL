# Windows NESticle 0.42 UI fidelity

The installed application is `bin/nesticle.exe`. The reference is the original
`NESTCL95.EXE` from the user's collection, SHA-256
`759b0cd77170ce16b5b370d2072626f095410333c2e47d4b364002cc974c31c2`.
The archive copy is unchanged.

The audit covers every menu tree, including nested CPU Debug, movies, WAV
logging, resolution and input menus. It compares labels, order, key names,
shortcut columns, selected rows, checkbox states and settings-only dispatch.
The original GUI resource, large/small fonts and icons are used.

| Area | Restored behavior |
| --- | --- |
| About | Original 295x75 contents, portrait, build/copyright strings, title and button. The 0.42 title is `Bow to the fecal-lord`, without an exclamation mark. `Buddy says:` belongs to earlier versions. |
| Shortcuts | Original key table, including F1–F10, and native menu column placement. Unknown scan values retain `<none>`. |
| ROM loading | Classic file/folder/drive list, icons and selected-ROM header summary. Load, Enter and double-click operate on the selected entry. |
| NES views | Side-by-side pattern tables, two physical name tables, 12-pixel palette swatches and native waveform bars/dots. |
| Editors | Native CHR pixel/swatch layout, attribute selection, RGB sliders, and retargeting an already open editor to another tile/color. |
| Header | Write updates the ROM's 16-byte header and reloads it. |
| Input | Original type order, keyboard redefinition, center/sweep calibration, quarter-range thresholds, button capture and disabled-button display. |
| Other dialogs | Native sizes, fonts, labels and controls for timing, directories, sound, movies, WAV logging, messages, resolution and network setup/status/chat. |
| Actions | Working patch/file outputs and dialog buttons; original register-dump text, current-mirroring changes, network name validation and received-chat format. |

`tools/reference_gui_test.py` executes the actual original PE constructors,
fonts, images, widget/menu draws and selected handlers. It passes **722 checks**,
including **277 full-buffer pixel cases**, with **zero failures**. The name-table
fixture uses the original tile blitter. Only host CRT/filesystem/DirectDraw
operations are bridged, and focus is explicitly set for drawing cases. NES
palette indices are normalized from native 64 to host 224 before comparison.

`tools/frontend_test.py` passes **64 scenarios**, including real click/Enter
actions, disposable ROM-header writes, movies, WAV and patch outputs, joystick
calibration, button capture, keyboard-binding persistence, remapped virtual
gamepads and cursor/menu/dialog cleanup. CPU, audio, renderer and local netplay
regressions also pass. Reports and image pairs are beside the installed binary;
`bin/reference-gui/comparison.html` presents selected comparisons.

Reproduce with:

```powershell
python tools\reference_gui_test.py bin\nesticle.exe
python tools\frontend_test.py bin\nesticle.exe
```

These results establish the listed coverage, not exhaustive executable
equivalence. SDL window/audio/controller APIs, Ctrl+O's host picker, modern
configuration and bounded malformed-input handling remain adaptations. The
classic File-menu picker is restored. Standardized SDL button numbers replace
legacy physical device numbering. Host netplay supports 1–64-frame latency,
although the native form's 16-bit control is retained. Original Windows event
loop/focus equivalence, physical gamepads, original-GUI state/movie use and
SDL-to-original network interoperability remain unverified. Further evidence
and emulation limits are in `RECOVERY.md`.
